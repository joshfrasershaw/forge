# Forgepath Trades

A design-led web studio serving UK trades businesses.

Static, responsive multi-page website. Open `index.html` locally or deploy the repository to a static host such as Cloudflare Pages.

## Before publishing

- Replace demo project artwork with licensed portfolio images and real case studies.
- Add verified reviews, results, phone number and package prices.
- Configure a working contact form endpoint and privacy/legal pages.
- Confirm enquiry destination and domain.
